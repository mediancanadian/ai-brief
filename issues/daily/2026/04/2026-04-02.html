2026-04-02 Thursday edition

Google releases Gemma 4 and ships free AI video in Google Vids with Lyria 3 and Veo 3.1

Google DeepMind launched Gemma 4, its most capable open model family for agentic and multimodal tasks, while Google Workspace added free AI video generation via Lyria 3 and Veo 3.1. H Company pushed the computer use frontier with Holo3, and the Gemini API gained Flex and Priority inference tiers for cost and latency control. AWS published domain-restriction guidance for agent deployments, and HuggingFace papers showed strong community interest in simulation, RL credit assignment, and agent security.

What matters today

Google Gemma 4

Google DeepMind released Gemma 4, its most capable open model family, built for advanced reasoning and agentic workflows with on-device deployment via HuggingFace Hub.

  • Most capable open model release from Google to date, targeting on-device and local deployment.
  • Built for multimodal understanding and agentic task execution across complex workflows.
  • Available on HuggingFace Hub with no API dependency or data residency constraints.
  • Positioned as a direct open-weights competitor to Meta Llama and Mistral model families.
  • Relevant for enterprises building agent systems that require a Google-backed base without cloud API costs.

Google Vids AI video

Google Vids added free AI video generation powered by Lyria 3 for music and Veo 3.1 for footage, integrated directly into Google Workspace.

  • Lyria 3 generates AI music; Veo 3.1 generates AI video footage inside the same Workspace environment.
  • Free tier removes the cost barrier that limited enterprise adoption of AI video tools.
  • No separate tool or subscription required: creation, editing, and sharing happen inside Google Workspace.

Holo3 computer use

H Company released Holo3, a model advancing autonomous GUI, browser, and desktop application operation by computer use agents.

  • Targets the computer use agent frontier: autonomous operation of GUIs, browsers, and desktop apps.
  • Released by H Company, a lab focused on agent-native model architectures.
  • Extends the capability boundary for agents executing multi-step tasks in real software environments.

Gemini API inference tiers

Google added Flex and Priority inference tiers to the Gemini API, letting developers trade response latency for lower cost.

  • Flex tier accepts variable response times in exchange for reduced pricing per request.
  • Priority tier guarantees low latency for latency-sensitive production workloads.
  • Gives developers explicit control over the cost-latency tradeoff at the API level.

Research worth watching

  • CARLA-Air: Unified Air-Ground Embodied Intelligence

    Unified Unreal Engine simulation for joint drone and ground vehicle agent training with photorealistic environments. Highest vote count this period at 339.

  • FIPO: Future-KL Influenced Policy Optimization

    Discounted future-KL divergence improves credit assignment in RL training for LLMs, extending reasoning chain length and math problem-solving accuracy. 330 votes.

  • ClawKeeper: Safety Protection for OpenClaw Agents

    Real-time security framework for autonomous agent runtimes: skill-based, plugin-based, and watcher-based protection across the agent execution stack. 182 votes.

  • LongCat-Next: Lexicalizing Modalities as Discrete Tokens

    Unified multimodal autoregressive processing by converting all modalities to a shared discrete token space via visual transformer. 137 votes.

Also in AI today

  • AWS published guidance for restricting agent internet access using Network Firewall rules to limit AgentCore to approved domains only.
  • Terminal Agents Suffice for Enterprise Automation found that simple terminal-based coding agents match or exceed complex tool-augmented agents on enterprise tasks.
  • GEMS introduced multi-agent optimization with persistent memory and domain-specific skills for multimodal generation across general and specialized domains.
  • MiroEval released an evaluation framework for research agents covering adaptive synthesis, agentic factuality verification, and process quality beyond final-answer accuracy.
  • All Roads Lead to Rome introduced Multi-Group Policy Optimization to prevent reasoning diversity collapse in RL-trained vision-language models.
  • Unify-Agent combined external knowledge retrieval, multimodal reasoning, and grounded generation for world-grounded image synthesis.
  • ViGoR-Bench measured how close visual generative models are to zero-shot visual reasoners across cognitive dimensions.
