Google cuts the time software makers get to fix bugs

Tencent's new voice model searches the web mid-call, a Huawei-backed project lets agents write their own plugins, and a voice test shows which assistants still talk over people.

What matters today

Bug-fix time cut

Google's Project Zero cuts the time software makers get to fix bugs it reports.

  • Full 90: from November 13, every bug it reports to a company goes public 90 days later, fixed or not. The extra 30 days for users to update are gone.
  • Shrinking: 60 days from February 2, 2027, then 30 days from January 3, 2028.
  • Why: AI lets attackers find bugs, or work them out from a patch, almost at once. Project Zero now finds several a week where it once found a few a year.
Why it mattersAI speeds up attackers and defenders alike. Anyone shipping software has less time between a bug report and a public exploit, so shipping fixes fast becomes part of the product.

Voice that searches mid-call

Tencent releases Hy Realtime, a voice model that can use tools.

  • Live since November 13 in Yuanbao voice calls and Tencent's customer service. An API on Tencent Cloud is coming, with no date given.
  • What it does: works out what people mean when they trail off or correct themselves, decides on its own when to search the web, and sings songs on request.
Why it mattersVoice assistants are moving from answering to doing things during the call. Tencent proves it on its own users and support lines first, then sells the same model to everyone else.

Agents add their own features

openJiuwen lets agents build and install their own plugins.

  • How: a user describes a feature, and the WorkSwarm agent writes, packages and installs it without touching the app's code. A plugin that breaks can be rolled back.
  • Open source: released November 13 by the Huawei-backed community, with WorkSwarm's code on GitHub under Apache-2.0. A plugin can run sessions on Claude Code or Codex.
Why it mattersFeatures no longer all come from the product team: each user's agent can add its own. That makes safe install and rollback more important than the roadmap.

Research worth watching

  • Voice AI that knows when to stay quiet

    OpenMOSS tested its MOSS-Live voice system against OpenAI's and ByteDance's. It answered speech not meant for it 2% of the time, against 68% for GPT-Live-1, but trailed GPT-Live-1 on multi-step tasks.

    Why it mattersTalking over people is now measurable. Test it before a voice agent joins real calls.

  • Scope agents so people can coach them

    LangChain and Actively AI say agents fail mostly for lack of know-how that lives in people's heads. Actively moved from one agent per sales account to one per type of job, so reps review similar work together.

    Why it mattersGive agents goals that are easy for people to review, since feedback is how they get better.

What developers are debating

  • Lovable apps leak data: a study of Lovable-built apps found private data readable without a login; developers argued that easy app builders make easy targets, and the author answered questions. 842 points, 319 comments.
  • Qwen3.8-27B on small GPUs: Unsloth's updated compressed versions drew developers comparing quality and speed on home graphics cards and Macs. 251 points, 83 comments.
  • DeepSeek V3 in 200 lines: a rebuild of the model's three main ideas in about 190 lines of JAX; developers praised it as a way to learn how models work. 236 points, 22 comments.
